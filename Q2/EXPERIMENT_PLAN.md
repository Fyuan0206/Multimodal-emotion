# Q2 第二轮实验计划：局部连续缺失下的鲁棒性验证

日期：2026-09-25。状态：**实验设计，尚未实现或执行第二轮实验。** 当前 `run_q2.py` 和 Slurm 脚本仍对应第一轮实现；不能把重新运行现有脚本视为完成本计划。

## 1. 实验要回答的问题

在附件2训练集学习模型参数，在验证集选择配置、早停轮次和决策规则，最终对附件3全部30条样本预测情感极性及强度。需要分别回答：

1. 连续片段增强是否改善局部缺失条件下的性能？代价是否表现为完整输入性能下降？
2. 多模态融合相对文本基线是否有效？可靠性门是否有额外贡献？
3. 缺失文本、语音、视觉，以及不同位置、长度的连续片段，分别造成多大影响？
4. 哪些错误在输入完整时已存在，哪些是遮蔽新增的错误？

结果以实测为准。若多模态或增强没有改善，应在论文中说明，不能仅凭模型结构宣称鲁棒性提升。

## 3. 阶段A：先完成数据与缺失协议审计

### 3.1 数据边界与检查

- 使用附件2 `aligned_50`：train 3395条，valid 728条；保持同一特征版本。附件2 test 不加入本轮训练或调参。
- 附件3仅在模型和输出规则冻结后最终推理，不用其预测分布调整增强概率、阈值或模型。
- 检查ID及可用的视频来源标识、各模态形状、标签范围、有限值、填充、天然全零行和已有缺失；记录划分间重复ID或来源重叠，不能静默删除或重划官方数据。
- 归一化统计及类别权重只从train估计。valid不参与梯度更新或归一化拟合。
- 核查 `[UNK]` 是否确为题目定义的缺失标记；普通未知词和缺失标记可能共用token 100。无法确认时，将其列为接口假设，并在训练/验证上报告替代解释的敏感性，不能声称已恢复真实缺失标签。

### 3.2 连续片段定义

对样本非填充的内容序列，记长度为 L。给定比例 r，申请长度 `k=max(1,round(r*L))`，在原有顺序中遮蔽一个连续区间。联合缺失使用同一时间区间作用于指定模态，属于同步联合缺失协议。

对于每个被遮蔽模态，区间外必须保留至少一个原本可观测的位置；同时统计该区间实际移除了多少个原本可观测的位置。不能通过事后随机恢复区间内部的一个点来满足约束，因为这会破坏连续缺失定义。

位置按区间中心落入序列前/中/后三分之一划分；在目标区域的可行起点中采样。长度大时，可行中心范围会收缩，报告实际起点和中心，不能假定前中后三组间隔完全相同。

如果指定长度、位置不存在可行区间，将该“样本—条件”标记为不可行，不偷偷缩短长度或改换位置。每格报告可评估样本数、不可行数、天然整模态缺失数和实际移除数。条件间规律优先在共同可评估样本上比较，并附全部可行样本结果，避免样本组成变化冒充缺失效应。天然整模态缺失样本另行报告，不能计作人工局部缺失。

同时记录两种比例：`区间长度/L`、`实际移除观测数/该模态原观测数`，不混称一个“缺失率”。

### 3.3 文本处理一致性

新实验统一采用“构造受损token序列 → 固定BERT重新编码 → 按观测掩码聚合”。完整输入也用同一编码流程，并抽查其与附件2预计算特征是否一致。保留原attention及特殊token逻辑；具体缺失token表示按数据协议审计结果锁定。

文本、语音、视觉共享对齐索引；不能删除文本token后造成其余模态移位。固定BERT不进行情感任务微调，所有模型共享相同特征缓存。缓存键包含数据哈希、样本ID、掩码、编码器revision和预处理版本；池化实验优先保存聚合特征，避免保存所有网格的完整BERT序列。

**阶段A通过条件：** 形状、数据划分和掩码检查通过；人工局部缺失没有把原本存在的目标模态全部抹去；不可行条件有明确记录；文本编码流程一致。

## 4. 阶段B：6组模型 × 5个种子的主实验

T/A/V分别为文本/语音/视觉。第一阶段继续使用现有轻量池化网络，先确认机制是否有效，不同时更换编码器和模型主体。

| 编号 | 输入 | 连续片段增强 | 可学习可靠性门 | 用途 |
| --- | --- | --- | --- | --- |
| T0 | T | 无 | 不适用 | 完整训练的文本基线 |
| T1 | T | 有 | 不适用 | 文本模型自身的增强收益 |
| M0 | T+A+V | 无 | 无 | 普通多模态基线 |
| M1 | T+A+V | 有 | 无 | 与M0比较增强收益 |
| M2 | T+A+V | 无 | 有 | 与M0比较门控收益 |
| M3 | T+A+V | 有 | 有 | 与M1比较门控收益、与M2比较增强收益 |

共30次训练，种子固定为2026、2027、2028、2029、2030。M0–M3构成增强×门控的完整2×2对照。T1与M3用于检查引入非文本信息的实际价值。

公平性要求：

- 每个种子使用相同样本顺序、训练与验证掩码；同形状共享模块使用相同初始权重，不再使用“种子+变体序号”。不同结构独有参数单独初始化并记录。
- 每个epoch为每条样本安排1个原始视图+3个视图槽。增强组填入固定的连续遮蔽视图，无增强组重复原始视图，保证每轮训练样本呈现次数、batch数、优化器更新次数一致。早停导致的总步数差异单独报告。
- T1与多模态增强组使用同一模态组合计划。组合不含文本时T1输入保持原样，不能另外让文本组承受更多文本遮蔽。
- 无门控组保留当前固定可用比例权重作为明确对照，不将其描述为完全忽略缺失信息的模型。模态投影、聚合统计和预测头设置固定。
- 训练增强沿用7种非空模态组合等概率采样、区间比例均匀采样10%–70%；先执行可行性检查并记录实际分布。每个种子的增强视图预先生成，跨模型复用。

预注册训练参数：模态投影64维、融合层128维；SmoothL1(beta=0.5)+0.7×加权交叉熵；AdamW，学习率1e-3，weight decay 1e-4，batch size 128，最多30轮，patience 6，dropout沿用当前配置。输出范围[-3,3]。本轮先不做大范围超参数搜索。

## 5. 阶段C：模型选择与联合输出规则

### 5.1 固定选择协议

提前冻结一套验证选择掩码（mask seed 4101），覆盖7种模态组合×3位置×3长度。按格等权计算平均MAE和Macro-F1，避免某格样本更多就获得更大权重。

选择分数沿用：

`S = MAE_clean + mean_grid(MAE) + 0.6 × [2 - F1_clean - mean_grid(F1)]`

clean表示不额外施加人工缺失，允许原数据本身有缺失；不能称为“每个模态都完美可观测”。模型选择和早停统一使用下节的强度统一解码：每个候选检查点先在选择掩码上确定τ，再计算S并保存该检查点与τ。双头分类的中性偏置仅用于对照分析，网格预设为[-0.3,-0.2,-0.1,0,0.1,0.2,0.3]，不能把该对照的评分冒充最终输出评分；同时保留未校准指标。

在M0–M3中按5个种子的平均S选择Q2多模态配置，T0/T1作为公开报告的竞争基线。若文本优于所有多模态模型，必须报告，不人为排除其结果。最终配置选定后采用其种子2026的早停检查点，不挑5个种子中偶然最佳者。

### 5.2 输出语义一致性实验

保留两种预先指定的规则，比较全部4项指标及不一致率：

1. 双头原始预测：校准分类头输出极性，回归头输出强度。
2. 强度统一解码：将回归值裁剪至[-3,3]；若绝对值≤τ，则输出Neutral、强度0；其余按正负号输出Positive/Negative及原回归值。τ候选为0、0.05、0.10、0.15、0.20、0.25、0.30。

τ只在验证选择掩码上按S确定，平局取较小τ。报告统一解码相对双头规则的Accuracy/F1/MAE/r变化，分类头仍可作为联合训练辅助任务。最终提交采用验证选择的统一解码阈值，以使极性和强度遵守同一语义；不能在查看附件3预测之后逐行修正。该输出约束是本方案的设计选择，不冒称题目明确规定了独立双头预测非法。

最终舍入也应复检：非中性强度不能因舍入变成0；优先保存足够精度，并在解码规范中规定舍入顺序。

## 6. 阶段D：缺失规律、消融和不确定性

### 6.1 主要评估矩阵

| 维度 | 水平 |
| --- | --- |
| 模态类型 | T、A、V、T+A、T+V、A+V、T+A+V |
| 位置 | 前、中、后，以连续区间中心定义 |
| 区间长度比例 | 15%、35%、55% |
| 诊断掩码种子 | 5101、5102、5103、5104、5105 |

每个检查点评估无人工缺失条件及63格，每格5套固定掩码；可行起点唯一时允许重复但标注唯一掩码数。所有模型共享掩码，不训练315个独立模型。训练种子与缺失掩码种子分别管理。诊断掩码不用于追加调参；它们仍来自同一验证集，不能因此宣称独立测试集性能。

每格记录Accuracy、三分类Macro-F1、MAE、Pearson r、样本数、每类支持数、实际移除位置数、原始可用率、相对clean的ΔMAE及ΔF1。Pearson遇到常数预测等不可定义情形记NA并解释。F1固定三类并明确零分母处理。

### 6.2 比较顺序与图表

1. 基础性能：6模型的clean与网格平均指标，5训练种子均值±标准差。
2. 模块消融：M1−M0、M2−M0、M3−M1、M3−M2；同时比较T1−T0及M3−T1。
3. 类型效应：固定位置和长度后比较T/A/V，再展示组合缺失。组合缺失同时改变受损模态数，不能直接归因于某个单一模态。
4. 长度效应：各类型分别画15%/35%/55%的MAE、F1曲线；无人工缺失作为单独参照。
5. 位置效应：固定类型及35%长度比较前中后，再用63格热图展示交互。
6. 展示混淆矩阵、真实强度—预测强度散点图、误差分布和分类别指标。

附件数据没有秒级时间戳，本文用“连续对齐位置数及比例”作为时长代理，不转换为秒。结论限定为该代理和当前长度范围；局部非单调结果如实报告。

### 6.3 不确定性

- 训练随机性：报告5个种子的均值和标准差。
- 配对比较：所有对照使用相同样本、相同掩码。保存逐样本预测，以原始样本为重采样单位，不能把同一条样本的5次遮蔽当成5个独立样本。
- 使用2000次配对bootstrap；若存在可验证的视频来源ID，按来源分组重采样，否则按样本并说明局限。每次重采样重新计算各掩码的指标，再对掩码和训练种子平均，给出差值的95%区间。该区间主要反映验证样本抽样不确定性，训练种子波动另报。
- 预先指定M3对M2、M1、T1为重点比较，其余条件作为描述性分析。区间跨0时表述为证据不足，不把微小点估计差写成稳定优势。

## 7. 阶段E：错误归因

为每个验证样本关联真实标签、clean预测、受损预测、区间起止、模态类型、实际覆盖率，计算误差增量和类别翻转。分类别说明负向、中性、正向的召回率及MAE。

区分：原本预测错误且遮蔽后仍错、原本正确而遮蔽后变错、遮蔽后改善、始终正确。对绝对误差、误差增量排名靠前的样本及固定随机样本选取约12例，按统一规则展示，避免只挑支持预期的例子。

“文本反转表达”“情感转折位置受损”“非文本信息可能补偿”等解释必须附实际文本、缺失区间或可用证据。缺乏原始音视频证据时写成待验证解释，不能从相关性直接认定因果。

## 10. 执行顺序与资源安排

1. **P0：实现并检查协议。** 数据审计、连续缺失可行性、文本重编码、相同步数、随机种子、评分和解码一致性。添加针对这些风险的小型检查，不在全量实验后才发现协议错误。
2. **P1：缓存与试跑。** 使用Q1现有环境和1张A100，先测少量样本的BERT编码耗时与缓存大小；做一个种子的短轮次冒烟验证，确认GPU、日志、恢复、指标和输出正常。试跑结果不当正式结果。
3. **P2：正式主实验。** 6组×5种子，独立保存检查点、配置、状态和日志；中断后从已完成单元继续，避免重复计费。接近作业截止时间不启动预计无法结束的新单元。
4. **P3：固定评估。** 缓存并复用诊断掩码特征，完成网格、配对区间、解码比较及错误归因，再冻结配置。
