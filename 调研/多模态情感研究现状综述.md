## 一、研究脉络与总体格局

### 1.1 五代演进

多模态情感分析（Multimodal Sentiment Analysis, MSA）自 CMU-MOSI / CMU-MOSEI（Zadeh et al., ACL 2018）建立基准以来的十年演进，可清晰划分为五代：

| 代际 | 时间 | 代表方法 | 核心思想 | MOSEI 典型水位（口径见第五章） |
|---|---|---|---|---|
| 第一代 | 2017–2018 | TFN、LMF、MFN、Graph-MFN、bc-LSTM | 统一表示空间中的张量外积 / 低秩分解 / 记忆网络 | Acc-2 78–82，MAE 0.57–0.60 |
| 第二代 | 2019–2021 | MulT、MFM、MISA、MAG-BERT | 跨模态注意力 Transformer；表示解耦为模态不变 + 模态特异子空间 | Acc-2 84–85，MAE 0.55–0.56 |
| 第三代 | 2022 | Self-MM、MMIM、CubeMLP、CENET、TETFN | 自监督伪标签多任务、分层互信息最大化、纯 MLP 三轴混合 | MAE 0.526–0.531，Acc-2 85–86 |
| 第四代 | 2023–2024 | ALMT、FDMER、CHFN、DLF、PMR、OGM-GE、AGM、ReconBoost；TFR-Net、IMDer、GCNet、CoKD/CorrKD、EMT、DMD、P-RMF | 语言引导去噪、优化层面模态均衡；同时系统研究缺失 / 噪声模态 | MAE 0.513–0.536，Acc-2 85–87 |
| 第五代 | 2025–2026 | MRCF、TLRA、PRLF、DIB、MRUF、MIG-HCL、UEFN、SIEVE、ProMMA；PRISM、KAN-MCP；MSAmba / AlignMamba / Cobra；MLLM 化路线 | 把"缺失模态"重构成显式的模态可靠性估计问题；原型 / 概念式内在解释；方法论反思 | MAE 0.506–0.544，Acc-2 84.5–87.1（完整模态） |

三点总体判断：

1. **基准已接近饱和。** 在 aligned 设置、预抽取 BERT 特征、非零二分类口径下，MOSEI 的 Acc-2 从 2021 年的 85% 区间推进到 2025–2026 年的 86.5–87.1%，MAE 从 0.53 降到 0.506（见第五章），改进空间被压缩到 1–2 个百分点。领域重心随之从"刷点"转向"诊断"。
2. **增长最快的子方向是模态缺失鲁棒性。** 2023 年以来 MOSEI 上的新工作半数以上以缺失 / 噪声模态为设定，并已形成"换模型不换数据"的统一数据格式生态（几乎所有方法直接读 `aligned_50.pkl` / `unaligned_50.pkl`），这是本赛题最大的结构性便利。
3. **2026 年出现明确的方法论反思。** arXiv:2609.11247（《The Illusion of Balanced Multimodal Sentiment Analysis: Beyond the Limits of Optimization-Based Methods》，2026-09-10 提交，arXiv comment 标注 "Accepted at Interspeech 2026"；本次核验中一条检索路径因工具编码错误返回 not-found，已由 arXiv API id_list 直接复核确认论文存在）用统一评测框架给出否定性结论：**没有任何一种基于梯度 / 损失的模态均衡策略能稳定超过 Late Concatenation**，性能对超参敏感，比例校准也给不出一致增益；其诊断是"loss 不是效用、gradient 不是重要性"。该结论直接影响本赛题 Q3 的"模态作用程度"应该如何度量（见第四章）。

### 1.2 当前主流范式（四条跨方法共识）

- **特征形态收敛：** BERT-base-uncased 最后一层 768 维词级隐状态（文本）+ COVAREP 74 维（声学）+ FACET 4.2 / OpenFace 35 维（视觉），序列长 50（aligned）/ 500（unaligned）。**MISA、Self-MM、MMIM、ALMT、DLF、MRCF、LNLN 等 SOTA 全部使用预抽取特征而不做端到端 BERT 微调**（唯一例外 MAG-BERT）。这意味着附件 2 提供的就是这些论文实际使用的特征形态，纯 CPU 下可完整复现该条 SOTA 曲线。
- **文本主导：** MCAF、MAESTRO、MVFA、VG-TPT、SentiLLM 等 2025–2026 工作一致把文本当作锚点模态（文本路由、文本引导提示、视觉注入冻结文本表示）。
- **解耦 / 对齐替代简单拼接：** 模态不变 + 模态特异、共享 / 私有 / 噪声三子空间、原型引导最优传输对齐成为标准组件。
- **缺失当作显式可靠性问题：** 2026 年共识是"能补"不等于"该补"——SIEVE（arXiv:2607.17262）的 per-sample oracle 分析显示全模态输入只对少数样本最优，"是否修复"本身应成为可学习的样本级决策；ProMMA（arXiv:2604.05558）主张"生成前先评估"。

### 1.3 评测协议分裂：本领域最大的方法论风险

**同一模型在不同论文中相差 4 个点以上是常态**，这是本次调研最需要强调的结论：

- ALMT 自报 MOSEI Acc-7 = 54.28（arXiv:2310.05804，EMNLP 2023，Librosa+OpenFace 特征）；LNLN（arXiv:2409.20012，NeurIPS 2024）用同一套 MMSA 特征复现仅 49.98（且该行实际取自 r=0.1 分率表，非完整模态）；PRISM（arXiv:2604.05873）转引 ALMT 为 53.62。
- Self-MM 自报 MOSEI MAE 0.530（arXiv:2102.04830，AAAI 2021，unaligned）；MMSA `result-stat.md` 记 self_mm MAE 53.09（即 0.5309，一致）但 Has0-Acc-2 为 83.76，而 Self-MM 原文同一指标为 82.81——**同一模型同一指标两个可靠来源不一致，引用必须二选一并注明来源**。
- **Acc-2 / F1 的 a/b 方向在不同论文中定义甚至相反：** Self-MM / MMIM / DLF / ALMT / MRCF / PRISM 为"左 = 负/非负（Has0），右 = 负/正（Non0）"；LNLN 为"左 = 负/正，右 = 负/非负"。直接抄表必错。
- 数据划分也不统一：HyCon 对应论文（arXiv:2109.01797）训练集写作 16,265，CubeMLP（arXiv:2207.14087）写作 16315/1817/4654，其余多为 16326/1871/4659；TLRA（arXiv:2605.16889）正文写 MOSEI 有 23,453 条（通行标注为 22,856，23,453 为原始视频段总数）。
- MMSA 的 `results/result-stat.md` 把 MAE 与 Corr **乘 100 存储**（self_mm 的 53.09 实为 0.5309），直接当百分比读会得出 MAE > 1 的荒谬结论；DLF 仓库的 result CSV 同样如此（MAE 53.61 实为 0.5361）。
- LNLN 仓库 README 内含 Corrigendum（更正 SIMS 上 Acc-5/Acc-3/Acc-2/F1/MAE/Corr = 34.68/57.32/73.15/69.18/0.515/0.387，并说明 ALMT 在 SIMS 上 F1 更正为 67.49、TETFN 在 MOSEI 上的数字无法更正）。引用任何 README 指标前先检查是否有勘误。

**可复现的交叉验证实例（本报告自行完成）：** PRISM 论文 Table 3 转引的 MISA MOSEI 行（MAE 0.557 / Corr 0.751 / Acc-7 52.05 / Acc-2 80.67·84.67 / F1 81.12·84.66）与 MMSA `result-stat.md` 的 misa 行完全一致，说明"† 引自 MMSA"的转引链是可靠的；而 PRISM 转引的 ALMT（0.530/0.774/53.62/81.54·85.99）与 ALMT 原文（0.526/0.779/54.28/84.78·86.79）明显不同，说明"† 转引"与"原文自报"不可混用。

## 二、Q1 相关：多模态特征提取与时序对齐的研究与工具现状

### 2.1 CMU-MOSEI 官方特征构造（复现目标）

CMU-MOSEI（Zadeh et al., ACL 2018；**正确标题为 "Multimodal Language Analysis in the Wild: CMU-MOSEI Dataset and Interpretable Dynamic Fusion Graph"，DOI 10.18653/v1/p18-1208，题面常见的 "Interpretable Fake News Challenge" 为误传**）自发布起就把"特征怎么来"和"怎么对齐"固化成两份可下载中间产物：

- **文本：** GloVe 或预训练 BERT，按词切齐；
- **声学：** COVAREP 74 维（官方仓库 `covarep/covarep` 的 `feature_extraction/COVAREP_feature_extraction.m` names 列表给出精确顺序：F0、VUV、NAQ、QOQ、H1H2、PSP、MDQ、peakSlope、Rd、Rd_conf、creak 共 11 维 + MCEP_0..24 共 25 维 + HMPDM_0..24 共 25 维 + HMPDD_0..12 共 13 维 = 74；F0min=50、F0max=500）；
- **视觉：** FACET 4.2 / OpenFace，30 Hz 抽帧、MTCNN 人脸框、FACS AU、六基本情绪、OpenFace 68 关键点 / 20 形状参数 / HoG / 头部姿态 / 视线；
- **对齐：** P2FA 音素级强制对齐 + 线性插值，全部按"词"这一公共时间轴池化，产出 50 帧 aligned 与 500 帧 unaligned 两个 pkl（MultiBench 分发）。

### 2.2 附件数据的实测结构（与官方规则的一致性证据）

本地实测（附件 2 的 4850 条 + 附件 3 的 30 条 + 附件 4 的 20 条）确认：

| 观测 | 结果 | 含义 |
|---|---|---|
| `text` 字段 | (N, 50, 768) float32，与 bert-base-uncased 最后层隐状态最大绝对差 5e-6…1.4e-5、相关系数 1.000000 | 文本模态可**逐位复现**（唯一能这么声称的模态）；embedding 层不匹配（corr 仅 0.03–0.21），说明取的是最后一层隐状态 |
| `text_bert` 字段 | (N, 3, 50) int64 = `BertTokenizerFast(raw_text, add_special_tokens=True, padding='max_length', truncation=True, max_length=50)` 的 [input_ids, token_type_ids, attention_mask]；3000 个 tokenizer 条目 0 处不一致 | 附件 3 / 附件 4 只给 `text_bert` 时必须自行跑 BERT 前向才能得到 768 维特征 |
| aligned 有效帧 | 恰为 text_len − 2 个非零帧；第 0 帧（[CLS]）与第 text_len−1 帧（[SEP]）在 400/400 抽样序列中 100% 为零 | 与 MMSA-FET `dataset.py` 的 `extract_align` 算法（词区间均值池化 + 按 `word_ids` 散射 + [CLS]/[SEP] 填零）逐字对应，从代码侧印证官方对齐规则 |
| 固有零填充 | 全部 50 个序列位中音频约 53.6%–54.7%、视觉约 55.5%–57.2% 的帧整行全零（含补零位）；但在有效区间（第 1…text_len−2 帧）内音频**无**内部全零帧，视觉有 13.3% 的样本含内部全零帧（均值 1.18 帧、最大 36 帧，即人脸检测失败） | **Q2 的缺失检测不能简单地用"整行为零"**，必须先统计固有零填充分布作为基线，再用游程长度阈值区分"固有稀疏"与"注入缺失" |
| unaligned 采样率 | audio_lengths = floor(音频时长 / 0.05) → 20 fps（50 ms hop）；vision_lengths = floor(解码帧数 / 2) → 15 fps（约 30 fps 视频隔帧取一）；20/20 个附件 4 样本满足 | 自建特征时的采样率规范 |
| 重编码误差 | audio_lengths 与 floor(时长/0.05) 存在 ±1 帧系统偏差（如 A4-04 官方 137 vs 重算 136）；音频流 start_time = 0、首包 pts = 0，无 AAC priming | 官方特征基于重编码前原始音频；任何自建对齐有最多 1 帧（50 ms）边界不确定性 |

### 2.3 词级对齐：官方做法 vs 现代工具

官方 MOSEI 用 P2FA（音素级强制对齐）+ 插值。2023 年至今词级对齐本身成为被重新审视的对象，最新证据一致指向**"粗对齐足够"**：

| 对齐器 | TIMIT 词级正确率 ≤10 / 25 / 50 / 100 ms | 平均边界误差 | 出处 |
|---|---|---|---|
| MFA（Kaldi GMM-HMM） | 41.6 / 72.8 / 89.4 / 97.4 % | 21.9 ms（TIMIT）/ 中位 12.5 ms | Rousso et al., Interspeech 2024（arXiv:2406.19363） |
| MMS（神经 ASR） | 18.6 / 43.5 / 75.7 / 94.7 % | 68.5 ms | 同上 |
| WhisperX | 22.4 / 52.7 / 82.4 / 94.2 % | 34.3 ms | 同上 |
| MFA 3.0（2026） | — | TIMIT 19.9 ms / Buckeye 21.8 ms（MMS 43.1/49.5、WhisperX 110.0/110.9、NeMo 78.2/88.6） | arXiv:2606.18466 |

注意两点：(1) 上述比较**仅统计被 ASR 正确识别的词**；(2) CMU-MOSEI 只需词级区间做平均池化，≤100 ms 的误差会被池化大幅平滑，这是关键利好。**但 MFA 只能 conda 安装、Windows 下无 G2P（无法给 YouTube 专有名词注音），torchaudio 在本环境完全不可用（import 报 WinError 127，缺 FFmpeg DLL），因此 MMS/WhisperX 路线也必须放弃。** 本报告的建议见第七章。

### 2.4 74 维声学与 35 维视觉的可复现边界

- **74 维顺序已从官方 MATLAB 源码确认**（见 2.1）。本地实证支持：d0 = F0（范围 [0, 492] Hz，对应 F0min=50/F0max=500）、d1 = VUV 二值、d2 = NAQ（[0, 0.28]）、d3 = QOQ（[0, 0.84]）、d4 = H1H2（dB，[−31, 35]）、d6 = MDQ（[0, 0.23]）、d8 = Rd（[0, 2.5]）、d11 = log 能量、d12–d23 = MFCC c1–c12（众数匹配 8–13/20）、d36–d39 恒为 0、d40–d60 ∈ [−π, π]（HMPDM 的 wrap 操作）、d61–d73 ≤ 0（log 域）。
- **只有 27 维可做数值近似：** d0/d1（parselmouth pitch，time_step=0.05、50–500 Hz；与官方 d0/d1 平均 r = 0.577、MAE = 17.75 Hz、VUV 一致率 0.792）与 d11–d35（25 维 librosa MFCC，与 MCEP 平均 |r| 0.59→0.12 递减）。d2–d10 的声门源参数需 SEDREAMS GCI + IAIF + MSP Rd/MDQ/peakslope（MATLAB），d36–d73 需 HMPD 分析；**GitHub 检索未检索到任何 Python 移植**。LSP 假设已被实证否证（无任何 LPC 阶数 × 奇偶半组合达到 6/20 众数匹配）。
- **35 维视觉特征的权威逐维定义未检索到**（CMU-MOSEI 论文只有散文描述，CMU-MultimodalSDK 只给 `VisualFacet42` 的 csd 文件名）。本机实测的经验分块为：d00–d29 连续量（均值 −2.9…+0.2）、d30–d31 ∈ [0,1]（概率量）、d32–d34 为头部姿态角（std 5.2–6.7，范围 [−22, 13]）。**论文中必须写"未检索到"，不得编造指标名。**

### 2.5 自建特征不劣于官方特征（重要量化依据）

MMSA-FET（ACL 2022 System Demonstrations，GPL-3.0）论文 Table 3（CMU-MOSEI aligned、二分类 Acc-2/F1）：

| 特征配置 | MISA | Bert-MAG |
|---|---|---|
| 官方 CMU-SDK 特征 + BERT 文本 | 82.96 / 82.98 | 83.41 / 83.47 |
| 自抽 BERT + eGeMAPS + OpenFace AU | **83.78 / 83.80** | 83.38 / 83.43 |
| BERT + 20d MFCC + 12d CQT + f0 + AU | 83.72 / 83.72 | 82.96 / 83.04 |
| BERT + wav2vec2.0 + AU | 82.16 / 82.23 | 83.57 / 83.58 |
| BERT + eGeMAPS + landmarks | 83.20 / 83.14 | — |
| BERT + eGeMAPS + landmarks + AU | **84.06 / 84.08** | 83.69 / 83.75 |

结论：用 librosa/openSMILE 自建声学特征 + 自建视觉 AU/landmark 在 MOSEI 上**不低于**官方 COVAREP+FACET；这为"在 CPU-only、无 ffmpeg 环境下自建流水线"提供了直接量化依据。MMSA-FET 本身不可直接用（依赖外部 ffmpeg 二进制 + Google Drive 上的 OpenFace 二进制/预训练模型 + ESPnet ctc_segmentation），只能借其时间对齐逻辑与特征维度约定。

## 三、Q2 相关：模态缺失鲁棒性方法全景

### 3.1 问题定义与缺失类型学

缺失模态研究的问题定义已从"能不能补"演化为"要不要补、怎么评、置信不置信"。**类型学是全部后续讨论的基础，本赛题的三种缺失必须分开处理：**

| 维度 | 类型 | 本赛题对应 |
|---|---|---|
| 缺失粒度 | **模态间缺失**（整模态不可用，7 种组合 {l} {v} {a} {l,v} {l,a} {v,a} {l,v,a}） | 附件 4 的 13 号样本 vision 全零；附件 3 中少数整模态置零的样本 |
| | **模态内缺失**（帧级 / 区间级随机擦除，0 填充或 [UNK]） | **附件 3 的主体模式**：aligned 版 audio 与 vision 共享同一零值掩码、游程多为 1–4 帧；unaligned 版两模态各自独立掩码 |
| 缺失率分布 | 共享缺失率 SMR / 不平衡缺失率 IMR | 附件 3 两套版本（aligned 共享 vs unaligned 独立）本质是 SMR/IMR 的混合 |
| 缺失与标签关系 | 随机丢弃（文献全部如此）/ 与标签相关 | **附件给定缺失是否与极性相关，赛前未有人检验过** |

缺失率统一定义为 MR = 1 − Σm_i / (L·M)，每模态独立以 MR 概率丢弃且保证至少剩一个模态（M=3 时 MR ≤ 2/3 ≈ 0.67，故多数论文把 0.7 当上限近似）。

### 3.5 五条关键结论

1. **"完整 ≠ 鲁棒"：** EMOE（MOSEI 完整 85.30，Avg 73.17）、DMD（完整 84.78，Avg 59.37）、Self-MM（完整 83.69，Avg 58.79）都是"完整模态很强、缺失即崩塌"的典型；GCNet（82.35 / 73.54）、CorrKD（82.16 / 74.02）、PRLF（85.44 / 76.24）做到了平衡。**Q2 应把"完整 Acc − 缺失 Avg"的落差作为核心展示指标。**
2. **单模态落差揭示模态价值：** 同一协议下 MOSEI {l} 通常 80–87，而 {v} 仅 32–68、{a} 仅 40–67。文本在 MOSEI 上几乎独当一面（PRISM：T only 85.09 / MAE 0.540，与 Full 86.57 / 0.519 接近；w/o T 崩到 62.85 / 1.007），视觉最弱。**评价"缺失鲁棒性"时 {v}、{a} 绝对值低是数据集特性而非方法失败，应报相对退化率。**
3. **缺失不是越补越好：** SIEVE（arXiv:2607.17262）去掉证据阀门后，GCNet+SIEVE 在 MR=0.3/0.5/0.7 上从 0.8201/0.7744/0.7165 掉到 0.7530/0.6707/0.6204；固定阈值（θ=0.5）也会掉到 0.7409/0.6738/0.6128。**"该不该修"必须可学习且带不确定性。**
4. **缺失模式本身是信息：** CMPL（arXiv:2608.20019）显式定义"训练期未见过的模态组合"（IMSAUMC）并声称带来 >5% 提升；MOSAIC 类工作从理论上证明块状缺失使每个观测模式对应不同的最优预测规则。附件 3 的两套缺失版本（aligned 共享掩码 vs unaligned 独立掩码）不应混为一个分布处理。
5. **缺失与标签的伪相关风险从未被度量：** 现有 MOSEI 协议几乎全部采用与标签无关的随机丢弃。**本题附件 1/2/3 的缺失是给定的，是否与标签相关（如负面情绪视频更常丢音频）值得先做按极性分组的卡方检验再决定是否需要在损失中解耦。**

### 3.6 与本赛题缺失模式的对应

- 附件 3 aligned 版：audio 与 vision **共享同一零值掩码**、游程多为 1–4 帧、文本完全未掩码 → 属于**模态内连续区间缺失（SMR）**；与 P-RMF 的"0 填充擦除"协议最接近。
- 附件 3 unaligned 版：两模态**各自独立掩码** → 属于**模态内缺失 + IMR**。
- 附件 4 的 13 号样本 vision 全零 → **整模态缺失**。
- **没有任何检索到的开源仓库提供"连续区间（run-length）缺失注入"以匹配附件 3**：MMSA 的 `data_missing` 是逐元素 Bernoulli，EMT-DLFR / TFR-Net 等也是随机缺失。Q2 必须自行实现连续块状缺失注入器。
- 附件 3 的 30 条中有 3 条 aligned 无注入缺失，可作为"缺失检测器"的负样本。

## 四、Q3 相关：可解释性方法全景

### 4.1 四代演进

1. **第一代（2019–2021）"注意力即解释"：** MulT / MISA / Multimodal-InfoMax 把跨模态注意力权重与模态私有-共享分解当作解释。同期 Jain & Wallace《Attention is not Explanation》（arXiv:1902.10186，NAACL 2019）与《Revisiting Attention Weights as Explanations from an Information Theoretic Perspective》（arXiv:2211.07714，EMNLP 2022）系统证明注意力分布与梯度重要性常不相关、可存在"等价预测但完全不同注意力"，使第一代解释的忠实性受到根本质疑。M2Lens（arXiv:2107.08264，IEEE VIS/TVCG 2021）把多模态模型解释做成可视化分析系统（全局/子集/局部三层，dominance / complement / conflict 三类交互），**但未检索到公开代码仓库**。
2. **第二代（2021–2023）结构化解释：** 情绪原因抽取（RECCON → ECF → SemEval-2024 Task 3）把"证据"落成可核验的话语 / 片段单元；反事实与因果方法用 do-干预检验解释是否真正驱动预测。
3. **第三代（2023–2025）生成式解释：** EMER（arXiv:2306.15401）提出任务与数据集；Emotion-LLaMA（620★）/ AffectGPT（ICML 2025 Oral，422★）/ EmoVerse / MicroEmo / XEmoGPT 用 MLLM 自回归输出"标签 + 理由"。评价指标从 BLEU/CIDEr/BERTScore 进化到 cue 级 EmoCue-360（语义相似度匹配的 P/R/F1）与解释-预测一致性指标。
4. **第四代（2025–2026）两条支线：** 其一是**原型 / 概念式内在解释**——PRISM（arXiv:2604.05873）用共享情感原型库 + 层级 DMR 门控，输出"视频帧按原型着色边框 + 音频波形时序叠加 + 词级原型高亮"，天然满足"可回看原始片段"；AGCM（arXiv:2502.10145）用面部 AU 作概念瓶颈，同时回答 what 与 where 并用 Concept Alignment Score 量化。其二是**模态贡献的可量化度量**——EmoMM（arXiv:2605.01024）提出 PSMV（Shapley 口径的模态边际贡献）、GTAR（真实对齐采纳率）、nMAS（归一化模态注意力密度）；arXiv:2609.11247 则从理论上指出"loss 不是 utility、梯度不是重要性"。

### 4.2 taxonomy

1) 注意力权重分析与跨模态注意力可视化（MISA / MMIM / Self-MM / M2Lens）——CPU 成本最低，但忠实性受质疑，必须补干预验证；
2) 梯度 / 显著性方法（Grad-CAM、Integrated Gradients、SHAP、Recipro-CAM、PaSE 的 Shapley 梯度调制、EmoMM 的 PSMV）——成本高，SHAP 在 50×74×3 输入上 CPU 实测不可行；
3) 原型网络（PRISM、PaSE、MAESTRO、TLRA）——轻量、天然带时间 / 词定位，**本题 Q3 首选**；
4) 概念瓶颈模型（AGCM、文本化模态描述 arXiv:2305.06162）——概念需领域标注，MOSEI 无 AU 标注是主要障碍；
5) 反事实解释（FACR arXiv:2606.15779、Counterfactual Reasoning for OOD MSA、Bias Purification、UniMEEC）；
6) 跨模态对比与对齐定位（EmoCue-360、EEA/FCR/EPC、GTAR/nMAS/VCC、EmoPrefer）；
7) 情绪原因抽取（RECCON、ECF、SemEval-2024 Task 3、MECGC、M3HG）；
8) 多模态 LLM 生成式解释（Emotion-LLaMA、AffectGPT、XEmoGPT、EmoVerse、Light-MER、C2F-Thinker）——CPU 不可行，仅可作离线教师或指标参照；
9) 不确定性感知解释（arXiv:2111.08456 NeurIPS 2021、arXiv:2404.08923 TCSVT、MIDAS、MRUF、QA-MoE）；
10) 干预式解释质量量化（横切所有类别）：comprehensiveness / sufficiency / AOPC（ERASER，arXiv:1911.03429，官方代码 `jayded/eraserbenchmark`，Apache-2.0）、pointing game / IoU、cue 级 F1、CAS、EEA/FCR/EPC、人评胜率。

### 4.3 解释质量量化指标（可直接实现的三件套 + 两个第二读数）

| 指标 | 定义 / 出处 | 本赛题可实现性 |
|---|---|---|
| comprehensiveness / sufficiency | ERASER（arXiv:1911.03429）：置零被解释为重要的 token/帧后看性能下降；只保留它们看性能保持 | 7 次前向/样本，727 条约 5089 次前向，CPU 完全可承受 |
| AOPC 曲线 | 同上 | 同左 |
| PSMV（模态 Shapley） | EmoMM（arXiv:2605.01024）：PSMV(m) = Σ_{m∈S⊆M} w_S [V(S) − V(S\{m})]，w_S = (|S|−1)!(|M|−|S|)!/|M|! | 三模态只需 2³−1 = 7 个前向；**建议作为"模态作用程度"的主口径** |
| GTAR | EmoMM：GTAR_m = Σ_{x∈S_tc} a^x_m c^x / Σ_{x∈S_tc} a^x_m（S_tc 为"恰好一个可用模态与真值不一致"的样本集） | 需先构造冲突子集，MOSEI 上可自建 |
| nMAS | EmoMM：nMAS^{ℓ,h}_m = (1/\|K_m\|) Σ_{k∈K_m} A^{ℓ,h}_{q,k} | 与 GTAR 显著正相关 |
| CAS（概念对齐分数） | AGCM（arXiv:2502.10145）：RAF-DB 上 AGCM-V 82.36 vs 无概念监督 66.10 vs CEM 78.62 | MOSEI 无 AU 标注，只能用 OpenFace 伪标签并明确声明；或改用"声学/视觉特征聚类中心"作概念、用轮廓系数替代 |
| EmoCue-360 | XEmoGPT（arXiv:2602.05496）：把解释中的情绪线索抽取成原子单元、向量化后用语义相似度算 cue 级 P/R/F1；论文证明其对 prompt 模板的 std/range 在 1e-3 量级、比 BLEU/CIDEr 更抗风格干扰 | 可用其**指标思想**做轻量版（sentence_transformers 4.1.0 已装）；XEmoGPT 本身为 4B MLLM，CPU 不可行 |

**EmoMM 的核心发现（VCC，Video Contribution Collapse）：** 在其自建的 CH-SIMS v2.0 + CMU-MOSI 双语基准（各 2000 样本）上，一致场景下三模态贡献约 1:1:1（视频 33.3%），冲突场景下视频贡献崩塌到 20.8%，单模态视频性能下降 16.0%（文本 10.4%、音频 9.8%）；GTAR 呈跨上下文稳定的 T > A > V 排序。**注意：该结论来自 MLLM 基准，不是 MOSEI。**

### 4.4 忠实性必须验证，且要防"泄漏式解释"

- arXiv:2606.26473（《When Does Quality-Aware Multimodal Fusion Matter? A Leakage-Safe Diagnostic for Decision-Level Dependence》，Interspeech 2026）提出置换可靠性分数的泄漏安全诊断，发现在 MOSEI 上置换可靠性分数**完全不改变性能**，除非该信号真能预测单模态正确性。这意味着大量论文报告的"可靠性权重"其实未进入决策。**我们的 Q3 必须用留一法误差增量 + 置换测试双重验证模态贡献度。**
- FACR（arXiv:2606.15779）用 do-干预检验"被引用的 AU 是否真正驱动预测"，在 UNBC-PAIN 上把一致率从 0.08 提到 0.57（代价 AUC 0.83→0.79）；但用学习到的因果图时与真正活跃 AU 的一致率仅 0.24。本题可做轻量版：随机置零 k 个被标记为重要的时间片统计预测改变率，置零被标记为不重要的时间片统计预测保持率，两比率之差即忠实性度量，CPU 友好。

### 4.5 MOSEI 无证据标注 → 本题最大方法学缺口

**MOSEI 系列无任何词级 / 帧级解释标注，而竞赛规则禁止引入其他情感数据集**，因此无法用监督方式学"证据定位"，只能靠：无监督 / 自监督结构（原型、门控）+ 干预式自评（comprehensiveness/sufficiency、GTAR、置换诊断）。这是 Q3 与文献最大的差异点，也是论文中应明确写出的"方法学边界"。

### 4.6 CPU-only 可行性排序（从轻到重）

注意力 / 门控权重（零额外前向）≈ 原型匹配（轻）< comprehensiveness/sufficiency 留一法（7 次前向/样本，可接受）< 梯度 / IG / SHAP（成本高）< MLLM 生成解释（不可行）。

**MLLM 路线的算力红线（本机 16 核 CPU 实测）：** 0.596B 模型 fp32 前向 L=256 为 2.101 s、L=512 为 4.623 s；训练步 7.691 s → 3395 样本/epoch 约 7.25 h、3 epoch 约 21.8 h；KV cache 解码 0.230 s/token → 60 token 解释对 727 条约 2.8 h。**bf16 在本机比 fp32 慢约 4 倍（16.3–20.6 s vs 4.623 s），int8 约为 fp32 的 60%，务必用 fp32 或 int8。** Light-MER（arXiv:2607.12787，ACM MM 2026）把模型压到 854.93M / 988.8 GFLOPs / 2.54GB，9 基准均值 74.61 反超 Qwen3-8B 教师 73.93，但对 4852 条样本的 CPU 推理仍不可行。**7B 级 omni-modal LLM 路线（Qwen2.5-Omni-7B + 4bit QLoRA，RTX 5090 32GB、峰值显存 10–21GB）在本题环境双重不可行，应整体排除。**

## 七、对我们三个问题的直接启示与建议技术路线

**总约束：** 纯 CPU（torch 2.8.0+cpu、16 核）、训练样本仅 3395 条（约为标准 MOSEI 的 20.8%）、只能使用赛题提供的 CMU-MOSEI 系列数据（训练/验证/调参/阈值选择/结果统计全部受限）、需全量可核验可复现并有处理日志、提交附件 ≤ 50 MB。

**总体路线：预抽取特征 + BERT 文本主导 + 轻量解耦/门控融合 + 显式缺失处理 + 结构化可解释输出，不微调 BERT、不用扩散重建、不用 MLLM。**

### Q1（特征提取与时序对齐）

**建议 1｜以附件 2 的 `text (N,50,768)` 为文本特征唯一来源，只对附件 3/4 自行复算。** 本地实测：附件 2 的 `text` 与 bert-base-uncased（transformers 4.57.6）最后层隐状态最大绝对差 5e-6…1.4e-5、相关系数 1.000000；`text_bert` 与 `BertTokenizerFast(max_length=50, add_special_tokens=True)` 的 3000 个条目 0 处不一致。附件 3/4 只给 `text_bert`，需自行前向（51 ms/样本，3395 条约 3 min）。**论文需标注：bert-base-uncased、12 层 / 768 隐维 / 12 头、取最后一层隐状态。** 预期指标：与官方差 1e-5 量级（可声称逐位复现）。工作量：低。

**建议 2｜声学实现 COVAREP 74 维中"可复现的 27 维子集"，并明确披露未复现的 47 维。** d0/d1 用 parselmouth（time_step=0.05、50–500 Hz，与官方 r=0.577、MAE=17.75 Hz、VUV 一致率 0.792）；d11–d35 用 librosa MFCC（与 MCEP 平均 |r| 0.59→0.12）。d2–d10（SEDREAMS/IAIF/MSP）与 d36–d73（HMPD）无 Python 移植，**在论文中写"未检索到 Python 实现，未复现"而不是编造**。依据：MMSA-FET Table 3 显示 eGeMAPS/20d MFCC+12d CQT+f0 在 MOSEI 上不低于官方 COVAREP（MISA 83.78 / 83.72 vs 82.96）。工作量：中。

**建议 3｜视觉用 OpenCV YuNet（320×320，13.1 ms/帧）+ 自建 AU/landmark 代理特征，35 维权威定义写"未检索到"。** 本机经验分块（d00–d29 连续量、d30–d31 概率、d32–d34 头部姿态）只能作为"实证分块"写入附录，不得当作官方定义。MMSA-FET 的证据：AU（83.2）≈ landmarks（83.14）≈ 两者并用（84.06）。工作量：中。

**建议 4｜时序对齐采用"词区间均值池化 + word_ids 散射 + [CLS]/[SEP] 填零"，并对齐附件 2 的采样率规范（音频 20 fps / 视觉 15 fps）。** 这与 MMSA-FET `extract_align` 的算法逐字对应，也被附件 2 数据本身证实（有效帧恒为 text_len−2，第 0 与第 text_len−1 帧 100% 为零）。**不要引入 MFA / WhisperX / MMS / NeMo**：MFA 在 Windows 无 G2P、torchaudio 在本环境损坏（WinError 127）、且 MOSEI 只需词级区间平均池化（≤100 ms 误差被平滑）。工作量：中。

**建议 5｜建立"38 对校验集 + 全量处理日志"作为 Q1 的可核验性核心。** 校验集 = 附件 1 ∩ 附件 2 的 18 对（train 11 / test 7）+ 附件 4 自带的 20 对；注意附件 4 的 id 已匿名化为 '01'..'20'，必须靠 `videos/` 目录匹配，用 (audio_lengths, vision_lengths) 签名匹配附件 1 视频只有 3/20 精确命中（±1 帧重编码误差）。日志至少记录：每条样本的 video_id/clip_id、解码帧数与时长、人脸检测成功率、各模态填充帧数、有效帧数、特征统计量与校验误差。工作量：中。

**建议 6｜把"附件 1 的 100 条视频 → 特征 → 在附件 2 上训练的模型上应用"这一跨集迁移单独成节。** 附件 1 与附件 2 仅 18 条交集，无法用公开仓库在附件 1 上复现；这是本题的独特设置，没有现成开源范式，需在论文中说明"特征抽取模型在附件 2 上训练/校准、在附件 1 上应用"的两段式设计。工作量：中。

### Q2（模态缺失鲁棒性）

**建议 7｜把"模态内连续区间缺失"与"整模态缺失"分成两条曲线报告，并把"完整 Acc − 缺失 Avg"落差作为核心展示指标。** 附件 3 aligned（共享掩码、游程 1–4 帧）属模态内 SMR；附件 3 unaligned（独立掩码）属模态内 IMR；附件 4-13 属整模态缺失。三者混为一个分布处理会同时违背 CorrKD（intra/inter 分开）、MuteBench 类分型与 CMPL（未见模态组合）的结论。工作量：低。

**建议 8｜缺失检测必须先区分"固有零填充"与"注入缺失"。** 附件 2 全部 50 个序列位中音频约 53.6%–54.7%、视觉约 55.5%–57.2% 为全零帧（含 [CLS]/[SEP] 与词尾补零），第 0 帧在全部 4850 条中恒为零；有效区间内音频无内部全零帧、视觉有 13.3% 样本含内部全零帧（均值 1.18、最大 36）。**因此"整行为零即缺失"的常用启发式在本题失效**，必须先统计固有零填充分布作基线，再用游程长度阈值（如 ≥3 帧）判定注入缺失。附件 3 中 3 条无注入缺失的 aligned 样本是缺失检测器的天然负样本。工作量：中。

**建议 9｜方法上选"模态 dropout 训练 + 显式缺失指示 + 可学习的'是否补全'门控（双分支）"，不用扩散重建。** 依据：SIEVE（arXiv:2607.17262）证明全模态只对少数样本最优、去掉证据阀门后 GCNet+SIEVE 在 MR=0.3/0.5/0.7 从 0.8201/0.7744/0.7165 掉到 0.7530/0.6707/0.6204；ProMMA（arXiv:2604.05558）主张"生成前先评估"；2026 年共识是显式可靠性估计（MRCF/TLRA/PRLF）优于生成式重建，其中 TLRA 明确不做输入级重建、只用模板/原型在表示与决策两层对齐，参数量与算力开销最小，**最适合 CPU 环境**。把"直接预测 vs 补全后预测"的双分支消融作为论文亮点。工作量：中高。

**建议 10｜消融按"缺失模态 × 位置（前/中/后段）× 时长（短/中/长游程）× 缺失率"做全因子，并引用 MissBench 的 MEI/MLI 作不均衡缺失下的诊断量。** 位置因子几乎无人系统研究（P-RMF/CMAD/AUMDF/CmIR 全部只扫描缺失率），这是本题可以做出增量贡献的空白点；ProMMA 给出的三档衰减律（10–30% 降约 2%、40–60% 降约 5%、70–90% 依数据集）可作为对照。工作量：中高。

**建议 11｜先做"缺失与标签相关性"的统计检验再决定是否解耦。** 按极性分组做缺失率卡方检验；若显著，则必须在损失中解耦"缺失即标签"的伪相关（现有 MOSEI 协议全部采用与标签无关的随机丢弃，完全没有度量过这一风险）。工作量：低。

**建议 12｜不要在 OGM-GE / AGM / PMR / ReconBoost 一类"优化层面模态均衡"上投入调参。** arXiv:2609.11247 用统一框架证明它们无法稳定超过 Late Concatenation、对超参敏感、比例校准也给不出一致增益；arXiv:2606.26473 进一步显示在 MOSEI 上置换可靠性分数完全不改变性能。把算力预算放在表示学习、语言引导与缺失鲁棒上。工作量：—（省下的预算）。

### Q3（可解释预测）

**建议 13｜主干用"原型 + 门控"承载解释（PRISM 范式），而不是 MLLM 生成式解释。** PRISM（arXiv:2604.05873，K=8、4 层 Transformer、5 seeds）在 MOSEI 上 MAE 0.519 / Corr 0.783 / Acc-7 54.55 / Acc-2 84.41·86.57，其输出形态（视频帧按原型着色边框、音频波形时序原型叠加、词级原型高亮）与赛题"可回看原始片段"逐项对应；消融显示去掉 DMR Gates 后 MOSEI MAE 0.519→0.534、Acc-7 54.55→52.18，说明门控值本身携带解释信息。CPU 完全可行。工作量：中高。

**建议 14｜"模态作用程度"用 Shapley 口径（PSMV）而非注意力/梯度口径，并同时报告 GTAR 作为第二读数。** PSMV 只需 7 次前向/样本（∅, T, A, V, TA, TV, AV, TAV），727 条约 5089 次前向，CPU 可承受；理论上由 arXiv:2609.11247 支持（loss 不是 utility、梯度不是 importance）。GTAR 需先构造"恰好一个可用模态与真值不一致"的冲突子集，在本题可自建，形成 Q2（缺失）与 Q3（完整）的分析闭环。工作量：中。

**建议 15｜解释质量用干预式指标量化，不能只画热力图。** 直接实现 comprehensiveness/sufficiency + AOPC（ERASER，arXiv:1911.03429，Apache-2.0）+ 轻量反事实忠实性（置零被标记重要的时间片看预测改变率 vs 置零不重要的看保持率，两比率之差即忠实性度量）。另建议报告置换测试 / 留一法误差增量的双重验证（防"泄漏式解释"）。工作量：中。

**建议 16｜主参考模态大概率是文本，但必须分指标报告。** PRISM：MOSEI T only 85.09 / MAE 0.540 与 Full 86.57 / 0.519 接近，w/o T 崩到 62.85 / 1.007；arXiv:2606.05713 在 MOSI 上 text-only MAE 0.552 优于 full 0.667，而 Acc-2 上 T+V(88.1) 优于 text-only(87.3)。**因此"强度回归主参考模态"与"极性分类主参考模态"可能给出不同答案，Q3 应分别给出。** 工作量：低（分析性工作）。

**建议 17｜文字解释用规则模板从结构化证据生成（零推理成本、完全可复现）；证据回放只挑代表样本。** 附件 4 的 20 条视频共 25.36 MB（均值 1.268 MB/条、99.4 kB/s），3 s 证据片段约 0.30 MB/条，50 MB 预算约容纳 160 条；对全部 727 条各存 3 s 片段约需 217 MB，超限。因此只挑"每类若干 + 高贡献冲突 + 缺失场景"的代表样本。若要做生成式解释对照，可用本地已缓存的 Qwen3-0.6B（约 4.6 min / 20 条）作为展示，但必须固定种子与模板。工作量：中。

**建议 18｜合规声明写进论文：训练与阈值只用附件 2 的 train/val；test 只跑一次；预训练权重仅作表征先验并标注名称/版本号/核心参数。** 需注意本环境无法检索到竞赛官方对"预训练模型是否算外部数据"的规则解读，此立场基于题面文本与 MOSEI 主流方法惯例的推断，**需自行判断并在论文中明示假设**。工作量：低。

## 八、风险与陷阱

1. **数字不可比（最高风险）。** ALMT 自报 MOSEI Acc-7 54.28，LNLN 用同套 MMSA 特征复现 49.98（且该行实为 r=0.1 分率值）；Self-MM 自报 Has0-Acc-2 82.81 而 MMSA result-stat 记 83.76；PRISM 转引 ALMT 53.62 vs 原文 54.28；CmIR 自行复跑 EMOE 得 MOSI Acc-7 45.2 / MAE 0.723，而 EMOE 原论文自报 54.1 / 0.536。**论文中必须加"不同论文数字不可直接比较"的声明，并给每行附四元组：划分 / aligned-unaligned / Acc-2 定义 / 缺失协议。**
2. **Acc-2 口径相反。** Self-MM / MMIM / DLF / ALMT / MRCF / PRISM 为"左 = 负/非负，右 = 负/正"；LNLN 为"左 = 负/正，右 = 负/非负"。抄表时按列名核对，不要按数值大小猜。MOSEI 约 75% 样本非负，Has0 远高于 Non0。
3. **MMSA result CSV 的 MAE 与 Corr 被乘 100**（self_mm 53.09 实为 0.5309；DLF 仓库 CSV 的 MAE 53.61 实为 0.5361）；另 LNLN 仓库披露旧版 MMSA `metric.py` 的 F1 计算有误。
4. **附件 2 不是 MMSA 官方文件。** 哈希不一致（`66e867aa…` vs `45eccfb7…`；`77eda14a…` vs `ad8b23d5…`），样本量 4850 ≠ 22856，划分 3395/728/727 ≠ 16326/1871/4659。公开指标只能作"方法参考"，不能作为预期结果；论文应给出"标准 MOSEI 公开指标（注明设置）"与"本赛题子集实测指标"两栏对照。
5. **三种缺失协议互不相同。** MRCF / LNLN 的表是"十档缺失率平均"，CorrKD 的表是"aligned + 零填充 + F1"，MissBench 是"SMR/IMR 模态级缺失率"，附件 3 是"模态内连续区间置零"。**不能把它们的数字当赛题缺失场景的预期值。**
6. **依赖 GPU 的方法必须排除。** 扩散恢复类（DiCMoR、RoHyDR、GSDNet）、Hi-MoE（6×RTX 4090、75 epoch、10 折 CV）、MITR-DNet（teacher-student 双模型）、7B omni-modal LLM（Qwen2.5-Omni-7B，RTX 5090 32GB、峰值显存 10–21GB）、Emotion-LLaMA / AffectGPT（7B + vllm/bitsandbytes/deepspeed + CUDA）、MAG-BERT（唯一端到端微调 BERT 的 SOTA）。GSDNet / C2MOE / SIEVE 报出的 MOSEI Acc-2 84–88 用的是 wav2vec-large + DeBERTa-large + MA-Net 特征，不能对标。

11. **环境坑。** torchaudio 不可用（WinError 127）；librosa.resample 极慢（9 s 音频 16.39 s，改用在 PyAV 的 `AudioResampler` 内直接输出 16 kHz）；opensmile 只有旧包名 `opensmile==2.6.0` 可装；Windows 上 `num_workers` 必须 0；bf16 比 fp32 慢约 4 倍；附件 4 的 pkl 由 numpy 2.x 序列化，本地 numpy 1.26 读取需 `sys.modules['numpy._core']=numpy.core` 垫片。
12. **小样本下方法假设可能失效。** 所有公开结论都建立在 22856 条完整 MOSEI 上；样本量降至约 21% 后，蒸馏式方法的教师-学生差距、课程学习的分组统计量、MoE 路由器的泛化都可能失效，必须自行做小样本消融。
13. **缺失-标签伪相关风险未度量。** 若某模态缺失与标签相关，模型可能学到"缺失即标签"；现有协议全部采用随机丢弃，完全没有度量过这一风险。
14. **指标定义本身的区分度问题。** MOSEI 类别高度不均衡使 Non0-Acc-2 接近随机水平（约 27–29），Acc-2 与 Acc-7/MAE 常常不单调（MMIM 的 Acc-2 低于 Self-MM 但 MAE/Corr/Acc-7 更好），且 LNLN 自述"分类与回归指标取自不同的最佳 checkpoint"——按单指标选模型会系统性高估。**建议所有模型选择都在验证集上按题面四指标联合早停。**
