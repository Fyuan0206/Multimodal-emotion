## 方法与特征工程

### 建模目标与整体流程

建立以原始视频为来源、以词级时间区间为桥梁、以文本WordPiece位置为统一输出索引的三模态特征提取模型。每个输出位置均能追溯到原文字符、音频时间窗口和视频原帧；对缺失观测、未对齐词和补齐位置分别保留掩码。

本轮采用的基线为：**BERT文本语义特征 + F0/VUV/MFCC声学特征 + YuNet人脸几何特征 + wav2vec2-CTC强制对齐 + 词区间池化**。预训练模型均冻结参数；问题1本轮不训练情感分类器，标签不参与特征提取。

完整流程：

1. 读取附件1样本表，以`video_id__clip_id`建立唯一主键，核对100条记录与原始MP4的一一对应关系。
2. 解码音视频，记录真实时间戳、有效采样数量、原视频帧索引和源文件SHA256。
3. 将音频转换为16 kHz单声道，保留给定英文转写；按真实视频时间戳进行视觉采样。
4. 分别提取768维文本特征、27维声学特征和15维视觉特征。
5. 使用已知转写与CTC声学模型估计词级时间边界，并保留原文字符映射。
6. 在每个词区间内池化音频和视觉特征，再映射到BERT的WordPiece位置。
7. 统一补齐到84个位置，保存原生序列、对齐序列、掩码、逐词来源映射和处理日志。
8. 执行全量数据契约检查、独立池化重算、重复运行比较及典型样本可视化。

### 原始样本预处理

从附件1的Excel读取 `(video_id,clip_id)` 和给定文本，以 `video_id__clip_id` 作为文件主键。标签不输入提取器。逐条校验文件存在、唯一性、SHA256、音视频可解码、实际PTS与采样数量。

音视频共同时间原点采用媒体最早流起点。音频重采样时保留PTS对应关系；若出现时间空隙，则保存空隙及无效掩码。本批100条未发现音频采样间断。

媒体容器时长不等同于解码信号有效时长。每条记录分别保存容器时长、视频首末帧及末帧持续时间、音频起点与采样数。本批音视频末端差最大约0.174秒，按真实时间保留，未强行拉伸信号。

文本使用附件提供的转写，通过字符偏移关联分词结果，不以自动识别文本覆盖原文。本批最长文本为84个token（含特殊token），6条超过50个token，因此选取84作为本批统一存储长度，保留全部原文。

### 三类特征的定义与提取

| 模态 | 工具或预训练模型 | 特征定义 | 原生组织与关键参数 |
|---|---|---|---|
| 文本 | google-bert/bert-base-uncased | 最后一层768维上下文隐藏状态 | Fast tokenizer保留字符offset；eval模式；float32；不截断 |
| 语音 | PyAV、librosa、Praat/parselmouth | 27维向量：[F0, VUV, MFCC0,…,MFCC24] | 16 kHz单声道；25 ms窗；50 ms步长，即20 Hz；40个Mel滤波器；基频范围50–500 Hz |
| 视觉 | OpenCV YuNet | 15维向量：归一化人脸框4维、检测置信度1维、5个关键点坐标10维 | 15 Hz目标网格选最近原帧，帧索引去重；输入320×320；阈值0.75；NMS 0.3；top_k=5000 |

**文本特征工程。** BERT表征用于描述上下文语义。特殊token保留其文本表示；补齐位置显式清零。该向量本身不是情绪概率或情绪强度。

**声学特征工程。** F0表示基频，VUV表示清浊音状态，25维MFCC描述短时谱包络；无声帧基频记为0、VUV记为0。MFCC使用Hann窗、DCT-II和正交归一化，Mel尺度设置由固定的librosa版本确定。Praat基频以最近帧映射到MFCC中心，并额外保存基频来源时间。该27维是自定义声学描述符；MFCC与MCEP不同，不称为COVAREP的精确复现。

**视觉特征工程。** 人脸框和关键点按原图宽高归一化，多人画面按最大人脸框优先、置信度次优选择。未检出人脸时输出零向量并将视觉有效掩码置为false。该15维只提供人脸位置与几何代理信息，不等同于表情动作单元AU或情感预测，也未覆盖场景、物体和肢体动作语义。

本轮原生声学量保留其物理单位和系数数值，未将F0、MFCC等混称为已完成统一量纲标准化。后续若训练预测模型，归一化参数应仅从相应训练集估计并保存。

### 跨模态时序对齐的数学模型

#### 已知文本的CTC强制对齐

使用`facebook/wav2vec2-base-960h`输出音频各声学帧的字符概率，将给定转写规范化为模型支持的字符序列，并保留规范化字符到原文词的对应关系。

设字符目标序列为y，在字符间插入blank得到扩展序列z。对声学帧t、扩展状态s，动态规划递推为：

```text
D(t,s) = log P(z_s | audio_t)
         + max{D(t-1,s), D(t-1,s-1), D(t-1,s-2)}
```

其中跨两状态的转移仅在当前符号不是blank、且`z_s != z_(s-2)`时允许。初始状态限于首blank或首字符，终止状态限于末字符或末blank。回溯最优路径后，按词合并字符时间区间，得到第i个词的区间`I_i=[s_i,e_i)`。

模型卷积步长为320个采样点，感受野为400个采样点，在16 kHz下分别为20 ms与25 ms；按感受野中心及半步长单元转换到秒，并限制在音频有效区间内。这些边界属于自动估计。

`src/ctc_align.py` 用numpy独立实现该动态规划与回溯，实现约束为：回溯必须覆盖全部T帧；负无穷是合法的“不可能转移/发射”取值，而空输入、NaN和正无穷一律拒绝；`tokens_to_spans(path, target)` 返回每个目标字符的左闭右开帧区间；不依赖torchaudio或其他深度学习框架。

含数字的词当前未擅自转换为某一种读法，保留未对齐状态。CTC字符发射概率的几何均值用于复核排序，低于0.2时列入优先检查清单；该分数未经校准，不能直接解释为边界正确概率。

#### 词区间内的跨模态池化

设模态m的原生特征为`x_j^(m)`，对应真实时间戳为`t_j^(m)`，有效性为`v_j^(m)`。对于词区间`[s_i,e_i)`，选择：

```text
J_i^(m) = {j : s_i <= t_j^(m) < e_i 且 v_j^(m)=1}
h_i^(m) = (1 / |J_i^(m)|) × Σ[j∈J_i^(m)] x_j^(m)
```

声学时间取特征窗中心，视觉时间取原视频帧真实PTS。窗口中没有原生采样点时，使用离区间中点最近的原生帧，并记录回退标记和时间距离。窗口有采样点但没有有效观测时，保持无效；最近视觉帧无脸时也不向更远处寻找替代人脸。

使用BERT字符offset建立“原文词→WordPiece”的对应关系，将同一词池化得到的声学与视觉特征赋给该词的各个子词位置。文本向量仍保留每个WordPiece自身的BERT表示。

#### 有效长度、填充与缺失规则

统一存储长度为L=84，每条样本输出：

```text
X_text   ∈ R^(84×768)
X_audio  ∈ R^(84×27)
X_vision ∈ R^(84×15)
```

- `text_length`为真实文本长度，含CLS和SEP；`padding_count=84-text_length`。
- 补齐位置三模态均为0，`padding_mask=true`。
- CLS、SEP没有原始音视频区间，对应声学和视觉特征为0。
- 未对齐词保留文本特征；音视频特征为0，并由`alignment_mask=false`区分。
- 人脸检测失败保留原生帧来源，同时标记视觉无效，避免把零向量解释为中性情绪。
- 无时间映射的位置在`token_times`中记为−1；真实0秒与缺失时间可以区分。

## 实施决策与证据边界

### 已实测的环境与输入

- 本机是macOS ARM，隔离环境Python3.12.13。`requirements.txt`固定直接依赖，`requirements-lock.txt`固定完整安装版本；`uv pip check`已通过。

- 标签表100条、主键唯一100个、MP4共100个、37个video_id，文件集合双向匹配，无遗漏或额外视频。独立证据为 `outputs/inventory_independent.json`。
- MP4容器时长范围2.257–29.288021秒，总计787.498018秒；此为媒体头口径，与题面描述范围不一致。最终还需对照实际解码PTS和音频样本数，不能修改原数据来迁就题面描述。
- 给定文本经实际BERT分词：最短7、最长84个token（含特殊token），6条超过50。因此Q1统一长度设为84，保留全部内容；问题1不必继承附件2的50位置截断。

### 方法选择

文本保留方案中的BERT最后层768维；音频保留F0、VUV和25维MFCC；视觉保留YuNet检测框、置信度和五点坐标15维。**MFCC不等于COVAREP中的MCEP**，27维应称为自定义声学描述符，不写成官方74维的精确子集。15维视觉特征为人脸几何代理，不能称为AU或真实情绪强度。

对齐选用公开的 `facebook/wav2vec2-base-960h` 16kHz CTC声学模型，使用给定文本进行CTC受约束路径对齐，不以ASR转写替换原文。通过Transformers直接推理，避免本轮为对齐引入完整WhisperX/MFA环境。该选择是本机工程可行的候选方案，其对MOSEI的时间边界精度仍需人工标注验证。

时间戳、CTC分数、未支持字符、无帧窗口、最近帧回退和视觉失检都保留记录。自动输出的词覆盖率不等于正确率；模型分数不是校准置信度。P90边界误差≤100ms只是原计划的验收目标，没有人工参考就不能填入实际成绩。全量运行可验证工程覆盖性，人工核验前应标记为候选特征。

本轮只使用附件1，不开展与附件2或附件4的跨集特征校准。原综述中的18对、20对及逐位复现数字属于用户提供的调研记录，本轮未独立核验，不作为本轮实验结论。
