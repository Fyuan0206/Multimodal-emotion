## 1. 视觉特征：当前证据不支持“充分表达情绪”

2026-09-25，服务器作业 **1529194** 完成，退出码0，耗时23秒。使用已回传的 A100 提取特征及附件1标签；诊断中的岭回归在计算节点 CPU 执行，并非GPU训练。计算日志见 `visual_results/server_run.log`。

100条样本、37个原视频组全部纳入，包括4条人脸零检出样本。标签为附件中的连续情感倾向值；没有逐帧表情、AU或六类情绪真值，因此本实验测量的是情感倾向预测关联，不能直接验证面部情绪识别。

### 方法与防止数据泄漏

- 外层5折 GroupKFold 按 `video_id` 分组，保证同一原视频的片段不跨训练/测试；这不等价于跨视频的说话人身份完全独立。
- 内层4折仍按原视频分组，在 `[0.1,1,10,100,1000]` 中以MAE选择岭回归正则强度。标准化在每次训练折内拟合；测试折不参与参数选择。
- 所有模型共享外层划分，100条均只产生一次折外预测。未根据结果删掉低质量样本或挑选有利划分。
- 使用原生视觉帧，避免尚未人工验证的词边界影响本次视觉诊断。仅对检出有效帧计算各维均值和标准差；全程未检出时统计量置零，同时保留检出比例、缺失指示和采样数/15秒的时长代理。
- “完整15维”由15维的均值/标准差及3个质量变量构成，共33维；不是更改了原15维特征。原15维含框位置尺寸、置信度、5个关键点坐标。
- “相对关键点”先以人脸框左上角为原点、宽高归一化，再汇总10个坐标，共23维含质量变量。它减小位置/尺度影响，但不能消除姿态、身份或检测误差，也不是面部动作单元。
- 文本对照取已有BERT有效内容token均值768维；文本加视觉为801维。仅用于独立诊断，不修改Q1提取器，不向Q2/Q3写入训练模型。
- MAE主基线是各训练折标签中位数；另报告训练折均值基线。MAE越低越好，R²以全部折外预测计算，可为负。

### 实测结果

| 方案 | 维度 | 折外MAE↓ | 折外R²↑ | Spearman相关 |
|---|---:|---:|---:|---:|
| 训练折中位数 | 0 | 0.603333 | -0.029180 | -0.173980 |
| 训练折均值 | 0 | 0.607667 | -0.055541 | -0.287921 |
| 检测质量/时长代理 | 3 | 0.613467 | -0.089514 | -0.289080 |
| 人脸框/置信度+质量 | 13 | 0.611699 | -0.080442 | -0.199035 |
| 相对关键点+质量 | 23 | 0.601947 | -0.047164 | -0.147281 |
| 完整15维汇总+质量 | 33 | 0.598157 | -0.035546 | -0.094023 |
| 文本 | 768 | 0.595952 | 0.041958 | 0.288419 |
| 文本+视觉 | 801 | 0.601324 | 0.037369 | 0.320223 |

完整视觉相对于中位数基线的MAE差为 **−0.005176**；按37个原视频成组重采样2000次所得描述性95%区间为 **[−0.034395, 0.026791]**，包含0。文本加入视觉后的MAE差为 **+0.005372**，区间 **[−0.030322, 0.045717]**，也包含0。负差表示改善。其余比较见 `paired_comparisons.csv`，全部区间跨0。

这些区间仅对固定折外预测进行组自助重采样，未重新训练模型，不覆盖训练集变化和划分变化的全部不确定性；不作为严格显著性检验。固定随机种子只用于统计重采样，没有生成或替代样本数据。

当前的原生15维汇总未表现出稳定的情感预测优势，也未证明相对于构图/检测质量的独立增益。文本对照本身也较弱，因此不能把结果推论为“所有视觉特征都无用”或“几何绝对没有情绪信息”。本实验仅限100条数据、均值/标准差时序汇总和岭回归探针；并未验证复杂时序模型、非线性表示或专门的表情/AU特征。

**论文建议表述（作者可采用，未替换正文）：**

> 为检验视觉几何表示与情感倾向的关联，对100条样本按37个原视频分组，实施外层五折、内层四折的嵌套交叉验证。完整视觉几何统计表示的折外MAE为0.598，训练折中位数基线为0.603，二者差异的组自助描述性区间包含零；视觉模型的R²为−0.036。现有实验未提供其充分表达情绪信息的证据。因此，本文将该表示限定为人脸空间几何及检测质量信息，不直接解释为情绪强度或面部动作单元。

后续若需支持“情绪特征”结论，应增加表情/AU等专门表示，并在更大、独立且具有相应标注的数据上评价。不能仅改名称或绘制更好看的曲线来补足证据。

## 2. 词边界：等待真实回听记录

已有回听表6词目前全部pending，未计算准确性数值。作者应继续使用 `../人工回听专项/回听填写.html`，填写真实参考边界并下载JSON。不要在CSV里补猜测值；确实不清楚的词标记 uncertain。

收到记录后，从 `work/Q1` 执行：

```bash
.venv/bin/python 独立验证专项/evaluate_listening.py \
  --review '/实际路径/Q1_六词回听记录.json' \
  --alignment outputs/server_a100/alignment \
  --out 独立验证专项/listening_results
```

也接受原字段结构的CSV。脚本校验词索引、原文、状态、成对边界、音频时间范围、回听人、日期、把握及播放速度。只将confirmed且自动对齐成功的词纳入误差计算；uncertain、不曾听到、转写不符均保留并计数。人工身份真实性仍取决于实际回听与记录，程序无法认证。

逐词报告起点误差、终点误差及两者最大值（毫秒）；汇总起止MAE、最大边界误差P50/P90、双端均在100ms内的比例及最大误差。比较对象始终为原A100边界，不用人工结果覆盖预测后再计算准确率。保留参考文件和逐词对齐JSON的SHA256。

**这6词是因跨平台差异而选出的定向排查样本，不是随机样本。** 即使6词都核验完成，也只证明该子集的误差状况，不能据此声称1932词全部准确或总体P90达标。若要报告更广泛准确率，还需完成既有10片段复核并说明其选样方法；严格总体估计需要预先设计具有代表性的抽样。

`test_listening.py` 的10项单元测试使用明确标识的合成夹具，仅验证误差公式和输入拒绝行为，不是人工标注，不进入论文结果。
