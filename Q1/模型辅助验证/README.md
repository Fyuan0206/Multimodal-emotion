# 模型辅助验证结果（非人工真值）

结论：可用于补充质检和列出疑点，不能替代人工准确性验证。主核查材料采用用户由GPT‑6 Pro整理的第二份，因为其中提供了faster-whisper-base运行脚本、完整识别文本和逐词时间；Kimi K3整理的第一份保留为补充意见。这里选择的是可检查程度，不是宣称第二份更准确。不覆盖原始CTC边界，也不把两份平均后当作真值。

## 来源与限制

第一份来自 `../模型辅助验证_KimiK3/Q1_有声10条回听记录.json`，198词，其中131条标为confirmed、38条transcript_mismatch、19条uncertain、10条not_heard。这些状态均为模型填写，confirmed不表示真人确认。CSV与JSON是同一批记录的不同格式，不能算两次独立核验。其旧metrics.json仍是空模板计算的pending结果，不是对新JSON的验证。

第二份来自 `../模型辅助验证_GPT6Pro/机器辅助核查/asr_check.json`，实际识别后端为faster-whisper-base CPU int8，非GPT‑6 Pro直接生成的语音时间。脚本未提供原文提示，但没有保存固定权重版本/哈希及完整运行环境，且说明记录了OpenMP冲突绕过。因此属于可检查的探索性ASR材料，不是已完全复现的精度基准。此轮没有重新执行其ASR，仅重新计算其结果与现有资料之间的关系。

第一份备注称base/small一致，未附完整分模型输出，且有“与系统对齐pred位置一致”的表述。两份可能共享Whisper base，第一份也可能看过CTC预测，不能声称独立双模型验证。

已检查第二份10个WAV与现有有声回听包哈希相同，参考文本与现有逐词JSON相同，198个主键与源词一致。时间合法性检查发现15条ASR词记录的零时长或越界问题，详见时间合法性问题.csv；这些记录不参加边界差异比较。非零音频不等于转写正确，也不代表能清晰识别。

## 实测差异

| 比较 | 可比较词数 | 最大双端差中位数 | 最大双端差P90 |
|---|---:|---:|---:|
| CTC与Kimi候选时间 | 150 | 155.0ms | 1342.5ms |
| CTC与ASR精确词匹配 | 93 | 122.5ms | 966.5ms |
| Kimi与ASR精确词匹配 | 88 | 90.0ms | 399.0ms |

这是条件性模型差异，不是误差、准确率或人工P90。150词包括19个uncertain候选，不能称全部已确认。精确词匹配通过英文词序列匹配确定；重复词可能匹配错位置，低文本一致性片段中偶然匹配的常用词不保证语义对应。未匹配、无时间或非法时间均不参加该项统计，分母不得写成198。

10条中5条的ASR与给定转写词序列相似度低于0.2：`-mJ2ud6oKI8__6`、`-iRBcNs9oI8__3`、`-hnBHBN8p5A__6`、`-yRb-Jum7EQ__5`、`-yRb-Jum7EQ__1`。该阈值只是本次质检优先级，不是错误判定阈值；可能是素材/转写错配，也可能是识别失败。不能凭ASR推测修改原标签、转写或删掉样本。

## 论文可用表述

> 在工程一致性核验之外，对10条按时长选取的有声片段进行模型辅助转写与边界交叉核查。保留独立ASR输出及另一份模型辅助逐词记录，比较其与给定转写和CTC候选边界的一致性。核查发现部分片段存在较大的转写差异和边界分歧，因此将相关结果作为质检提示，未将模型输出视为人工参考真值，也未据此报告人工边界准确率。模型来源可能重叠及候选时间依赖原预测的风险限制了证据独立性。

“独立ASR”仅指脚本不以给定转写为提示，并不表示两个辅助资料来源统计独立。

## 复现与文件

在Q1根目录运行 `.venv/bin/python 模型辅助验证/compare_reviews.py`。

- 逐词模型比较.csv：保留三路时间、候选状态与差异。
- 逐片段转写核查.csv：给定文本、识别文本和质检优先级。
- 时间合法性问题.csv：15条需要排除的时间记录。
- metrics.json：统计、来源哈希、明确的human_reference=false。

本结果补充Q1工程质检，不解决总体边界准确性或疑似素材转写错配的最终判定。原始两份目录保持不变。
